# RoboBuddy Lab v1 Legacy Archive

These 50 scenario definitions are preserved as legacy source data. The ScenarioV2 catalog, workbench, grading, drafts, and progress do not load or reinterpret them.

After the one-time v2 catalog build, `missions/lab-assistant/v2/legacy-v1-export.json` records each v1 path, byte count, and SHA-256 digest. The v2 workbench can separately export existing browser-side v1 drafts as a read-only JSON archive.

Do not edit or regenerate v1 definitions as part of ScenarioV2 maintenance.
