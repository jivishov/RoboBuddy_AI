# SO-101

Robot id: `so101_follower`.

Tier 1 supports SO-101 simulation and an optional local bridge path. Frontend joint limits are conservative educational placeholders and are not authoritative hardware limits.

Hardware rules:

- use local bridge only
- no direct browser hardware control
- calibration is required before real movement
- STOP remains available
- bridge fails safely if LeRobot is not installed

The real adapter imports LeRobot lazily in `bridge/robobuddy_bridge/adapters/so101_lerobot.py`.
