Quick Start

Write real Python that builds safe robot commands.

This interpreter runs real Python, but the robot API is provided by RoboBuddy. Your Python code uses the arm object to build a command list. RoboBuddy validates that list, then runs it through the same preview and robot runner used by Blockly. 

arm.home()
arm.move_joint("base", 100, speed=50)
arm.wait(0.5)
print(arm.get_angles())
Safety Model
The Python code does not write directly to the robotic arm. It creates commands, then RoboBuddy checks limits, speed, timing, and command shape before running them.

Real Python

The editor runs Python in Pyodide. Variables, loops, lists, functions, math expressions, and print() work.

Restricted Sandbox

No direct serial, DOM, file, network, package install, input(), or normal import access is exposed to student code.

Runner Controlled

After validation, movement is executed by RoboBuddy's existing program runner, preview, stop, and emergency-stop paths.

Arm API

The arm object

arm is a RoboBuddy classroom object. It is available automatically in the Python editor. Do not import it.

arm.move_joint(joint, angle, speed=50)

Move one joint to a target angle. Use a joint name such as "base" or a number from 0 to 5. Speed must be 1..100.

arm.move_joint("shoulder", 120, speed=45)

arm.move_arm(..., speed=50)

Plan all six joints in base, shoulder, elbow, wrist rotation, wrist tilt, and gripper order. Omitted joints keep their current planned angle. Speed must be 1..100.

arm.move_arm(
  base=90,
  shoulder=110,
  elbow=70,
  wrist_rot=90,
  wrist_tilt=100,
  gripper=80,
  speed=45
)

arm.home()

Move to the default home pose: all six joints at 90 degrees.

arm.home()

arm.wait(seconds)

Add a delay between movements. The accepted range is 0 to 30 seconds.

arm.wait(0.5)

arm.gripper_open(speed=55)

Open the gripper to the classroom default open angle, 50. Speed must be 1..100.

arm.gripper_open()
arm.wait(0.3)

arm.gripper_close(speed=55)

Close the gripper to the classroom default close angle, 120. Speed must be 1..100.

arm.gripper_close(speed=45)

arm.smooth_move(joint, start, end, seconds=1.5)

Move one joint gradually from a start angle to an end angle. Duration must be 0.2 to 10 seconds.

arm.smooth_move("shoulder", 65, 120, seconds=1.2)

arm.save_pose(name)

Save the current planned angles under a pose name for the current Python run.

arm.save_pose("pickup")

arm.go_to_pose(name, speed=50)

Ask the runner to move to a saved pose. Speed must be 1..100. If the pose name is unknown, the runner reports that it was not found.

arm.go_to_pose("pickup", speed=45)

arm.emergency_stop()

Add an emergency-stop command to the generated command list. Use the red STOP button for immediate operator stop.

arm.emergency_stop()

arm.get_angles()

Return the current planned angles as a list in joint order.

print(arm.get_angles())

Gemini Page Syntax

Writing Gemini requests on the Gemini page

The Gemini page uses Google's google.genai style, but it runs through a RoboBuddy classroom shim. Your code captures one client.models.generate_content(...) request, the page sends it with the Session API Key field and Model selector, then response.text is replayed into your code.

Keep keys, model choice, and images in the page controls. Do not put an API key, local file path, or image bytes in Python. The Model selector is the model used for the real request, so keep the model string in code matched to the selector to avoid confusion.

Basic text request

Create a client with no API key argument, call generate_content once, then read response.text.

from google import genai

client = genai.Client()
response = client.models.generate_content(
  model="gemini-3.5-flash",
  contents="Explain one safe wave motion for RoboBuddy."
)
print(response.text)

Text parts

contents can be a string or a list of user text parts. Use parts when separate instructions make the prompt easier to read.

from google import genai

client = genai.Client()
response = client.models.generate_content(
  model="gemini-3.5-flash",
  contents=[
    {
      "role": "user",
      "parts": [
        {"text": "Plan a safe classroom robot motion."},
        {"text": "Use short steps and avoid joint limits."}
      ]
    }
  ]
)
print(response.text)

Supported config

The page accepts common GenerateContentConfig fields and converts them for the browser request.

from google import genai

types = genai.types
client = genai.Client()
response = client.models.generate_content(
  model="gemini-3.5-flash",
  contents="Return a short JSON plan for a safe wave.",
  config=types.GenerateContentConfig(
    temperature=0.2,
    thinking_config=types.ThinkingConfig(thinking_budget=0),
    response_mime_type="application/json",
    response_schema={
      "type": "object",
      "properties": {
        "summary": {"type": "string"},
        "steps": {
          "type": "array",
          "items": {"type": "string"}
        }
      },
      "required": ["summary", "steps"]
    }
  )
)
print(response.text)

Robot Python generation

Click Generate robot Python for robot code. Review the generated arm.* code, validate it, then run it.

from google import genai

client = genai.Client()
response = client.models.generate_content(
  model="gemini-3.5-flash",
  contents="Create a safe three-step wave for RoboBuddy."
)
print(response.text)
roboadmin.use_response(response.text)

Page limits

Use only one generate_content call per run. roboadmin.use_response(...) is a page replay helper, not direct hardware control.

The sandbox rejects API keys in Python and does not support streaming, chat sessions, local files, package imports, or multi-call scripts.

These examples adapt Google's Gemini API patterns for the RoboBuddy page. For full SDK behavior outside this lab, see Google's Generate content API, structured output guide, and image understanding guide.

Common Errors

Wrong joint name

# Wrong
arm.move_joint("wrist", 90)

# Use one of the documented names
arm.move_joint("wrist_tilt", 90)

Angle outside range

# Base is 20..130, so this fails
arm.move_joint("base", 180)

Speed outside range

# Speed must be 1..100
arm.move_joint("elbow", 90, speed=200)

Infinite loop timeout

# This does not finish building commands
while True:
  arm.wait(0.1)

The worker stops Python execution after 8 seconds. Use for loops with a fixed count.

Importing modules

# Do not do this in the lab sandbox
import math

# math is already available
print(math.sin(1))

Expecting a native robot library

arm is injected by RoboBuddy for this lab. It is not a standard Python module and does not exist outside this page.

Direct hardware access

Python cannot write to serial hardware directly. Use arm commands and RoboBuddy will run them safely.
