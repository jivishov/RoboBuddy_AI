Native-Windows SO-101 support matrix

Retrieval date: 2026-07-26
Target: native 64-bit Windows, x86-64, CPython 3.12 ABI
Current bundle terminal status: NATIVE_WINDOWS_BLOCKED

The status is narrow: the source implementation and offline cross-platform checks are complete, but the required Windows host, browsers, Android device, and robot were not available in the packaging environment. Nothing here establishes technical impossibility.

The machine-readable authority is bridge/windows_support_matrix.json; dependency enforcement remains centralized in bridge/pyproject.toml.

Kinematics decision

The required Windows backend is native_dls_v1:

  • semantic order is exactly shoulder_pan, shoulder_lift, elbow_flex, wrist_flex, wrist_roll;
  • the gripper never enters FK or IK;
  • public joint units are degrees; internal solver units are radians;
  • poses use x, y, z, w quaternions;
  • the bundled URDF digest must be 5ea6695846d5f04416116e75894b8b10627ed4ec559b907ccc9cb47f7a753860 and target frame must be gripper_frame_link;
  • position is the hard numerical contract; orientation is ignored at zero weight or treated as weighted best effort;
  • configured ceilings are 48 iterations and 20 ms, with classified fail-closed outcomes;
  • the configured 1.5 mm position residual is software numerical tolerance, not physical positioning accuracy.

A standard-library URDF-chain oracle and immutable reference corpus independently check production FK. IK results are independently forward-transformed before acceptance tests.

Browser/device qualification boundary

Gamepad API availability does not prove the physical Xbox mapping. Qualification must be repeated in current Chrome and Edge with explicit controller selection, neutral-state qualification, RT deadman, Fine override, pair selection only while idle, X measured hold, B STOP, poll-gap retirement, and explicit re-arm after STOP.

The Android path must first load https://<private-ip>:8443/ without a certificate warning. Only then may QR pairing be attempted. Verify window.isSecureContext, navigator.xr, one authorized WebSocket, release-to-hold, tracking/background/focus/pointer/transport retirement, reconnect state reset, unreachable-target rejection, and global STOP.
